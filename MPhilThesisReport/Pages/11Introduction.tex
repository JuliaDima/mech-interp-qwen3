\chapter{Introduction}

Understanding what neural networks actually \textit{compute}, rather than what they \textit{output},
is the central problem of mechanistic interpretability. A model that correctly solves arithmetic problems or chains
reasoning steps coherently need not be implementing anything resembling the algorithm a human would use.
Whether it does, where in the network that computation lives, and whether it can be manipulated predictably
are empirical questions that evaluation benchmarks cannot answer.

\section{Mechanistic Interpretability}
Anthropic's \textit{On the Biology of a Large Language Model}~\cite{lindsey2025biology} proposes
a reproducible methodology for approaching such questions on a large language model (LLM). Combining sparse autoencoders (SAEs)
with cross-layer transcoders (CLTs) and backward-pass attribution, it constructs dependency graphs
that trace information flow from input tokens through intermediate features to output logits.
The framework is the starting point of mechanistic interpretability work done in this thesis,
focused on how mathematical primitives are implemented by LLMs, and how these implementations can be improved
through insights from mechanistic interpretability.

Prior mechanistic work has established that small transformers trained on arithmetic tasks converge
on specific and inspectable algorithms rather than fitting statistical
regularities~\cite{nanda2023progress, zhong2023clock, quirke2024understanding,
quirkeneo2025understanding, musat2024clustering}.
Whether analogous structure arises in a large instruction-tuned model, trained without an explicit
arithmetic curriculum on substantially more diverse data, is considerably less clear and is a central concern
of this work. Furthermore, since mechanistic interpretability offers relevant insights into how these models
perform algorithmic tasks, we can make use of this knowledge to improve model performance on algorithmic tasks,
which is the focus of the second part of this thesis.

We take the open access model \texttt{Qwen3} as our subject model and integer addition as our primary task.
Addition is a reasonable prototype due to having unambiguous ground truth and being structured enough that prior work has identified non-trivial internal
mechanisms~\cite{nanda2023progress, quirke2024understanding}, and performance degrades in interpretable ways
as digit magnitude increases. We initially characterise the model's behaviour on addition using the existing attribution graph methodology given by \citet{lindsey2025biology}.
Beyond reproducing the attribution graphs, we perform intervention studies such as constrained patching to validate hypotheses regarding the underlying computation. We also
use linear probes to localise where arithmetic-relevant information is encoded across layers.

By drawing insights from our mechanistic analysis, we then proceed to improve model performance on mathematical primitives through modifying specific components of the model.
