\chapter{Reproducibility}
\label{sec:repro}

\section{Addition Arithmetic Circuits in Qwen}

\citet{lindsey2025biology} showed that Claude~3.5 Haiku, when presented
with prompts of the form \texttt{calc:~$a$+$b$=}, does not implement a
symbolic carry algorithm but instead activates a family of sparse
\textit{lookup table} features whose firing concentrates on the cells of
the operand space satisfying $a \bmod 10 = d_1$ and $b \bmod 10 = d_2$
for a specific digit pair $(d_1, d_2)$.  These features encode the ones
digit of $d_1$, $d_2$, or $d_1 + d_2$ and route this information directly to the output.
The present reproduction analyises whether the same mechanistic signature
appears in Qwen3-4B, trained independently on a different corpus and with
a different tokeniser, and whether the attribution methodology transfers to a 
model for which it was not originally calibrated.  The
analysis adopts the transcoder formalism and notation of
Section~\ref{sec:interp-methods}.

\subsection{Lookup Features}
\label{subsec:operand-plots}

For a prompt $\texttt{calc:~}a\texttt{+}b\texttt{=~}$, let $T$ be the
index of the \texttt{=} token.  The \textit{operand matrix} for feature
$(\ell, k)$ is

\begin{equation}
  M_{\ell,k}[a, b]
    \;=\; a_{\ell,k,T}
          \!\left(\texttt{calc:~}a\texttt{+}b\texttt{=~}\right),
    \qquad a, b \in \{0, \ldots, 99\},
  \label{eq:operand-matrix}
\end{equation}

obtained by scanning over the full $100 \times 100$ integer-pair grid.
The geometry of $M_{\ell,k}$ encodes the feature's sensitivity in an interpretable form.  
A feature that tracks the raw sum $a + b$
produces diagonal stripes of constant activation; one that tracks a
single operand produces horizontal or vertical bands; modular sensitivity
to the ones digit of either operand produces a period-10 repeating
structure.  A feature that fires selectively for a specific pair of ones
digits $(d_1, d_2)$ produces a regular grid of isolated point clusters,
concentrated on the $200$ cells where $a \bmod 10 \in \{d_1, d_2\}$ and
$b \bmod 10 \in \{d_1, d_2\}$.

To identify lookup candidates automatically, each feature is assigned the
concentration score

\begin{equation}
  s_{\ell,k}(d_1, d_2)
    \;=\;
    \frac{%
      \displaystyle\sum_{a,b}
        M_{\ell,k}[a,b]\;
        \mathbb{1}\!\left[
          a \bmod 10 \in \{d_1, d_2\},\;
          b \bmod 10 \in \{d_1, d_2\}
        \right]
    }{%
      \displaystyle\sum_{a,b} M_{\ell,k}[a,b]
    },
  \label{eq:lookup-score}
\end{equation}

which measures the fraction of total activation mass that lies on the
target grid.  Features are filtered by a minimum peak-activation
threshold to exclude dormant features, then ranked by $s_{\ell,k}$.
The top-ranked feature for the pair $(d_1, d_2) = (6, 9)$ -- the ones
digits of the focus operands $36$ and $59$ -- is taken as the reference
lookup feature and subjected to causal validation.  Two interventions are
applied.  In the \textit{inhibition} experiment, the feature's activation
is scaled by a factor $\beta \in \{1.0, 0.5, 0.0, -1.0, -5.0, -10.0\}$
before the decoder output is computed; if the feature is causally
necessary, driving $\beta$ below zero should monotonically weaken the
logit for the token representing the correct ones digit of $6 + 9 = 15$.
In the \textit{substitution} experiment, the MLP inputs at all layers
preceding the lookup feature's layer are replaced by those from the
prompt \texttt{calc:~39+59=~}, which has ones digits $(9, 9)$ rather than
$(6, 9)$; if the identified feature mediates the computation, the output
should shift from predicting ones digit $5$ to ones digit $8$.

\paragraph{Position-resolved feature scan.}
\citet{lindsey2025biology} observe that the features active during
addition in Claude 3 Haiku differ systematically by token position:
features at the operand tokens encode individual digit values, while
features at the delimiter token encode their combination.  To examine
whether an analogous positional structure is present in Qwen3-4B, the
operand scan of Equation~\ref{eq:operand-matrix} was applied at three
token positions in the prompt \texttt{calc:~}$a$\texttt{+}$b$\texttt{=}:
the ones digit of $a$ (position 4), the ones digit of $b$ (position 7),
and the \texttt{=} token (position 8).  At each position the top-15 CLT features by attribution edge weight were
selected; one representative per distinct ones-digit encoded is shown.
Figure~\ref{fig:operand-pos-scan} shows the resulting matrices.

At position 4, the selected features activate in vertical bands with
period 10 along the $a$ axis.  Activation is determined almost entirely
by $a \bmod 10$ and is insensitive to $b$.  At position 7 the pattern
is transposed: horizontal bands with period 10 in $b$, independent of
$a$.  The symmetry between the two positions suggests that the ones
digits of the two addends are encoded separately, with each operand
token carrying information about that operand's own digit.

The \texttt{=} token displays a more varied set of activation patterns.
Several features produce diagonal bands concentrated along contours of
constant $a + b$, indicating sensitivity to the sum rather than to
individual operand values.  Others show a periodic point-cluster
structure in which activation concentrates at cells where both
$a \bmod 10$ and $b \bmod 10$ take specific values; this is the
joint-modular structure captured by the score in
Equation~\ref{eq:lookup-score}, and it is the defining signature of the
lookup table features described in Section~\ref{subsec:operand-plots}.
A smaller number of features at this position show broader diagonal
regions reflecting coarser magnitude sensitivity rather than exact digit
values.

The positional separation visible in Figure~\ref{fig:operand-pos-scan}
implies that ones-digit information is encoded before the two addends
are jointly processed.  At the operand token positions, no retained feature shows sensitivity
to both $a$ and $b$ simultaneously; the
cross-operand joint representation appears only at the \texttt{=} token.
This ordering is consistent with the view that the network first reads
off each digit independently and only subsequently computes a function
of their combination.

\subsection{Behavioural Verification}
\label{subsec:accuracy-scan}

Before committing mechanistic resources to a single focus prompt, it is
necessary to establish that the model solves the task reliably across the
operand space.  A circuit identified on a prompt the model cannot answer
carries no mechanistic authority.  The accuracy scan therefore records,
for every pair $a, b \in \{0,\ldots,99\}$, the \textit{teacher-forced
confidence} at each output position.  Let
$\mathbf{y}^*(a,b) = (y^*_0, y^*_1, \ldots)$ denote the ground-truth
answer tokens for $a + b$.  The teacher-forced confidence at position $k$
is

\begin{equation}
  P_k(a, b)
  = P\!\left(
      y_k = y^*_k \;\middle|\;
      y_0 = y^*_0,\, \ldots,\, y_{k-1} = y^*_{k-1},\;
      \mathbf{x}(a,b)
    \right),
  \label{eq:teacher-forced}
\end{equation}

where $\mathbf{x}(a,b)$ is the token sequence for the prompt
\texttt{calc:~$a$+$b$=} and preceding positions are forced to their
correct tokens.  Equation~\eqref{eq:teacher-forced} isolates the residual
difficulty at each generation step by removing uncertainty due to
error accumulation in prior positions.

Figure~\ref{fig:positional-cascade} plots $P_k(a,b)$ for
$k \in \{0, 1, 2\}$.  At $k = 0$ the model must predict the leading
output token from the prompt alone; the grid mean is $\mu_0 = 0.233$,
reflecting genuine uncertainty over a substantial fraction of the operand
space.  At $k = 1$, once the first token is teacher-forced to the correct
value, mean confidence rises to $\mu_1 = 0.943$.  By $k = 2$ it reaches
$\mu_2 = 0.988$, with the only uncertain region being the upper-right
triangle where $a + b \geq 100$ and the answer carries into a third digit.
The cascade reveals that the central computational burden falls entirely on
predicting $y^*_0$: subsequent tokens resolve almost automatically given
the correct leading digit, a pattern that is consistent with a mechanism
that maps directly from the operand ones-digits to the output rather than
propagating carries sequentially.

Rather than varying smoothly with operand magnitude, the $k = 0$ panel of
Figure~\ref{fig:positional-cascade} shows that confidence is organised into
a period-10 grid aligned with the decimal ones-digit boundaries.  Within
each $10 \times 10$ block the within-block pattern repeats with the same
geometry, and this periodicity implies that $P_0$ depends primarily on
$(a \bmod 10,\, b \bmod 10)$ rather than on the absolute values of $a$ and
$b$.  This is the behavioural signature one would expect if the computation
were implemented by features selective to specific ones-digit pairs.

\paragraph{Prediction entropy.}
Confidence $P_k(a,b)$ measures whether the top-ranked prediction is
correct, but not how sharply the model has committed to any prediction.
A cell with low confidence might correspond either to genuine
distributional uncertainty or to a confident wrong prediction.  The
Shannon entropy of the truncated output distribution at position $0$,

\begin{equation}
  H(a, b)
  = -\sum_{j=1}^{K} p_{(j)}(a, b)\;\log_2 p_{(j)}(a, b),
  \label{eq:entropy}
\end{equation}

where $p_{(1)}(a,b) \geq \cdots \geq p_{(K)}(a,b)$ are the top-$K$
predicted probabilities, measures distributional spread independently of
prediction correctness.  The top-right panel of Figure~\ref{fig:positional-cascade}
plots $H(a,b)$ across the grid.  Low-entropy cells (where the model commits
decisively to a single token) form a period-10 grid aligned precisely with
the high-confidence regions in the $k = 0$ panel.
High-entropy cells (where the model distributes probability across several
candidates) are concentrated at and near carry boundaries and for large
operand values.  The agreement between the two maps establishes that the
model's decisiveness and its correctness are driven by the same underlying
structure, rather than by one compensating for the other.

\paragraph{Carry complexity.}
Each pair $(a,b)$ can be classified by the number of digit-column carries
arising in the sum.  Defining

\begin{equation}
  \kappa(a, b)
  = \begin{cases}
      0 & \text{no carry arises,} \\
      1 & \text{exactly one carry arises,} \\
      2 & \text{two or more carries arise,}
    \end{cases}
  \label{eq:carry-class}
\end{equation}

The top-left panel of Figure~\ref{fig:positional-cascade} shows the partition
induced by $\kappa$.  If Qwen3-4B were implementing a symbolic carry algorithm,
accuracy should deteriorate with carry complexity: pairs with $\kappa = 2$
should be hardest and pairs with $\kappa = 0$ easiest.
The bottom-left panel of Figure~\ref{fig:positional-cascade} contradicts
this prediction.  Regions of identical carry class exhibit substantial
internal variation in $P_0$, and the drops in confidence cut across carry
boundaries rather than aligning with them.  The period-10 grid structure
of $P_0$ persists within each carry class, unmodulated by carry count.
This dissociation between carry complexity and model accuracy constitutes
behavioural evidence that the computation is not organised around carry
propagation.

\section{Multilingual Circuits in Qwen}
% ============================================================

\citet{lindsey2025biology} showed that antonym completion in Claude~3.5
Haiku is not implemented by a monolithic circuit but by three functionally
independent components, each localised in a distinct portion of the
network.  When presented with a prompt of the form \textit{the opposite of
``small'' is ``}, the model activates a family of transcoder features
encoding the antonym \textit{operation} (what semantic relation is being
applied), the \textit{operand} (the concept whose opposite is sought), and
the output \textit{language} (which language the response should appear in).
By identifying source-exclusive and target-exclusive features for each
component in isolation and injecting the latter while suppressing the former,
they demonstrated that each component can be redirected independently without
disrupting the others.  The present experiment asks whether the same
factorised structure is present in Qwen3-4B, a model trained on a different
corpus with a different tokeniser.

The multilingual setting makes the factorisation hypothesis non-trivial to
test.  If the operation and operand components were language-specific,
features identified from an English prompt would carry no predictive power
over French or Chinese outputs.  The hypothesis predicts instead that the
features encoding the antonym relation and the concept of size are
language-neutral directions in activation space, remaining active across
prompts in all three languages, and that only the language component varies
with the surface language of the input.  This thesis reproduces three causal
interventions on Qwen3-4B, targeting the operation, operand, and language
components in turn, using the transcoder-based causal methodology described
below.

\subsection{Exclusive Feature Identification}
\label{subsec:exclusive-features}

For each experiment, a \textit{source} condition and a \textit{target}
condition are defined, differing along exactly one of the three components.
Let $a_{\ell,k}^{\,\mathrm{src}}$ and $a_{\ell,k}^{\,\mathrm{tgt}}$ denote
the activation of transcoder feature $k$ at layer $\ell$ and token position
$p$ under the source and target conditions respectively.  Taking the top-$K$
active features in each condition, a feature is \textit{source-exclusive} if
it is strongly active in the source condition and weakly active in the target,
and \textit{target-exclusive} if the reverse holds.  With exclusivity
threshold $\rho \in (0,1)$, the suppress set $\mathcal{S}^\ell$ and inject
set $\mathcal{I}^\ell$ at layer $\ell$ are defined as

\begin{equation}
  \mathcal{S}^\ell
    = \bigl\{k \in \mathcal{F}_{\mathrm{src}}^\ell
        : a_{\ell,k}^{\,\mathrm{tgt}} < \rho\cdot a_{\ell,k}^{\,\mathrm{src}}\bigr\},
  \qquad
  \mathcal{I}^\ell
    = \bigl\{k \in \mathcal{F}_{\mathrm{tgt}}^\ell
        : a_{\ell,k}^{\,\mathrm{src}} < \rho\cdot a_{\ell,k}^{\,\mathrm{tgt}}\bigr\},
  \label{eq:exclusive-sets}
\end{equation}

where $\mathcal{F}_{\mathrm{src}}^\ell$ and $\mathcal{F}_{\mathrm{tgt}}^\ell$
are the top-$K$ active feature indices at layer $\ell$ under the respective
conditions.  The threshold $\rho = 0.5$ was used throughout, so a feature
qualifies as source-exclusive only if the target condition activates it at
less than half the source-condition magnitude.  The sets $\mathcal{S}^\ell$
and $\mathcal{I}^\ell$ are disjoint by construction: a feature active at
comparable magnitude in both conditions satisfies neither criterion and
belongs to neither set.

\subsection{Causal Intervention Sweep}
\label{subsec:multilingual-intervention}

The intervention acts on the pre-MLP hidden state.  Let
$\mathbf{h}^{\ell,p} \in \mathbb{R}^d$ denote the post-RMSNorm input to the
MLP at layer $\ell$ and token position $p$, the vector on which the
transcoder encoder was trained to operate.  For each layer $\ell$ in the
designated range, $\mathbf{h}^{\ell,p}$ is projected through the transcoder
encoder, the resulting feature representation is modified according to
Equation~\eqref{eq:exclusive-sets}, and the altered output supplants the
standard MLP contribution at that position.

The feature activations produced by this projection are

\begin{equation}
  \tilde{\mathbf{z}}^{\ell,p}
    = \mathrm{ReLU}\!\left(
        \mathbf{W}_\mathrm{enc}^{(\ell)}\,\mathbf{h}^{\ell,p}
        + \mathbf{b}_\mathrm{enc}^{(\ell)}
      \right) \in \mathbb{R}^K.
  \label{eq:reenc}
\end{equation}

Source-exclusive activations are set to zero and target-exclusive activations
are augmented at intervention strength $\gamma \geq 0$,

\begin{equation}
  \tilde{z}^{\ell,p}_k \;\leftarrow\; 0,
  \quad k \in \mathcal{S}^\ell;
  \qquad
  \tilde{z}^{\ell,p}_k \;\leftarrow\; \tilde{z}^{\ell,p}_k + \gamma\,v_k,
  \quad k \in \mathcal{I}^\ell,
  \label{eq:suppress-inject}
\end{equation}

where $v_k = a_{\ell,k}^{\,\mathrm{tgt}}$ is the target-condition activation
magnitude of feature $k$.  The modified feature vector is then projected back
to residual space via the transcoder decoder,

\begin{equation}
  \tilde{\mathbf{o}}^{\ell,p}
    = \mathbf{W}_\mathrm{dec}^{(\ell)}\,\tilde{\mathbf{z}}^{\ell,p}
    + \mathbf{b}_\mathrm{dec}^{(\ell)},
  \label{eq:decode-multi}
\end{equation}

and computation propagates with $\tilde{\mathbf{o}}^{\ell,p}$ in place of
the standard MLP output at position $p$ and layer $\ell$, all other positions
and layers remaining undisturbed.  The next-token probability for each
monitored vocabulary index $t$ at the final position $T$ is

\begin{equation}
  \pi_t(\gamma)
    = \bigl[\mathrm{softmax}\!\left(\mathrm{logits}_T\right)\bigr]_t.
  \label{eq:pi-gamma}
\end{equation}

The scan is conducted over $\gamma \in \{0,\,\delta,\,2\delta,\,\ldots,\,\gamma_{\max}\}$,
yielding one probability curve $\pi_t$ per monitored token.  If the targeted
component is causally sufficient for the corresponding aspect of the output,
$\pi_t$ for the target-condition token should rise monotonically with $\gamma$
while the source-condition curve declines, constituting a directional
redistribution of probability mass.

\subsection{Three Causal Interventions}
\label{subsec:multilingual-experiments}

The three interventions differ in which component they target, at which token
position features are identified, and over which layer range the modification
is applied.  The layer ranges are grounded in the decomposition reported by
\citet{lindsey2025biology} for Claude~3.5 Haiku: the operation component
occupies the middle third of the network, the operand the early third, and
the language component the first fifth.  For Qwen3-4B with $L = 36$, these
correspond to

\begin{equation}
  \mathcal{L}_{\mathrm{op}}
    = \Bigl\{\bigl\lfloor\tfrac{L}{3}\bigr\rfloor,\,\ldots,\,
             \bigl\lfloor\tfrac{2L}{3}\bigr\rfloor - 1\Bigr\}
    = \{12,\ldots,23\},
  \label{eq:op-layers}
\end{equation}

\begin{equation}
  \mathcal{L}_{\mathrm{oper}}
    = \Bigl\{0,\,\ldots,\,\bigl\lfloor\tfrac{L}{3}\bigr\rfloor - 1\Bigr\}
    = \{0,\ldots,11\},
  \label{eq:oper-layers}
\end{equation}

\begin{equation}
  \mathcal{L}_{\mathrm{lang}}
    = \Bigl\{0,\,\ldots,\,\max\!\bigl(1,\bigl\lfloor\tfrac{L}{5}\bigr\rfloor\bigr) - 1\Bigr\}
    = \{0,\ldots,6\}.
  \label{eq:lang-layers}
\end{equation}

These ranges are adopted from Anthropic's analysis of a distinct architecture
and are not derived from the geometry of Qwen3-4B itself.  Whether they
correctly delimit the relevant layer segments for this model is an empirical
question that the results address.

\paragraph{Operation swap.}
The antonym task is presented in English as \textit{the opposite of
``small'' is ``}, with the alternative prompt \textit{a synonym of ``small''
is ``} as the target condition.  Features are identified at the final token
position $p = T$ over layers $\mathcal{L}_{\mathrm{op}}$.  The resulting
exclusive partition $(\mathcal{S}^\ell, \mathcal{I}^\ell)$ is transferred
without modification to antonym prompts in English, French, and Chinese.  The
monitored tokens are the antonym surface forms in each language and their
synonym counterparts.  If the operation features are language-neutral, the
English-derived partition should redirect the output toward synonyms across
all three languages.

\paragraph{Operand swap.}
The source condition is the English antonym prompt for ``small'' and the
target is the English antonym prompt for ``hot'', \textit{the opposite of
``hot'' is ``}.  Features are identified not at the final position but at
the \textit{operand divergence position} $p^*$, the first index at which
the token sequences of the two English prompts diverge.  This is the position
at which the words ``small'' and ``hot'' enter the context respectively, and
it is where the operand concept is hypothesised to be encoded.  The exclusive
partition is computed over $\mathcal{L}_{\mathrm{oper}}$ and applied at the
analogous divergence position in each language-specific antonym prompt.  The
monitored tokens are the antonym surface forms and the surface forms denoting
cold in each language.

\paragraph{Language swap.}
Three directed language pairs are examined: English to Chinese, Chinese to
French, and French to English.  For each pair, both the source and target
activations are drawn from antonym prompts in the respective languages, and
the exclusive partition encodes the contrast between two language contexts
rather than two semantic conditions.  The partition is computed at the final
position over $\mathcal{L}_{\mathrm{lang}}$ and the intervention acts on the
source-language prompt.  The monitored tokens are the antonym surface forms
in both languages.  If the language component is independently localised,
substituting target-language features for source-language ones should redirect
the output toward the target-language antonym, leaving the underlying semantic
relation undisturbed.


\subsection{Results}
\label{subsec:multilingual-results}

The intervention scans use $K=15$ active features per layer and an exclusivity
threshold of $\rho=0.5$.  Next-token probabilities are always evaluated for the
token that would actually follow the prompt, rather than for a token obtained
from a word in isolation.  This distinction is relevant in a multilingual
setting, where tokenisation is sensitive to the preceding quotation mark and to
the script of the surrounding context.  The same issue is especially visible in
the operand experiment: in French, both \textit{petit} and \textit{chaud} are
split across two subtokens.  The intervention is therefore applied to the full
operand span, and the plotted target is labelled as \textit{froid} even
though the measured probability is attached to its first predicted subtoken.

  operand intervention transfers across languages, whereas the language

The operation and operand interventions support a partially factorised account
of the computation.  Changing the semantic relation, or changing the adjective
whose antonym is requested, can redirect the model's answer while leaving the
surrounding prompt fixed.  The operand result suggests that the same
English-derived small-to-hot intervention produces the appropriate cold antonym
in English, Chinese, and French once the relevant token spans are treated
consistently.

For the language intervention, The English-to-Chinese
edit weakly increases probability on the Chinese answer token, but the effect
is not significant enough to constitute a genuine output-language swap.  The
Chinese-to-French and French-to-English interventions do not yield significant
results.  A broader supplementary intervention, in which language features were averaged
over the prompt and edited over all prompt positions, suppressed the original
answer but still failed to move probability to the target-language token.  This
suggests that the negative result is not explained by the choice of monitored
token alone.  Rather, for Qwen3-4B, the output-language component appears not
to be isolated by the selected early-layer MLP transcoder features. \textcolor{red}{refine}

\subsection{Attribution Graph Structure and Interactive Visualisation}
\label{subsec:attr-graph}

In this project, each attribution graph is stored as a JSON file containing three
components.  The \textbf{node list} records every active transcoder
feature: each node carries a layer index, a token position
(\texttt{ctx\_idx}), a feature identifier, and a feature type
(\texttt{CLT} for cross-layer transcoder features,
\texttt{E} for embedding-space nodes).  The \textbf{link list}
records directed influence edges between nodes; each edge has a scalar
\texttt{weight} representing the linearised attribution of the source
node's activation on the target node's logit contribution.
The \textbf{metadata} block stores the prompt tokens, the node-retention
threshold $N$, and the slug used to retrieve the graph.

To identify the top features driving a given output token one reads the
edges incoming to the target logit node, sorts by $|\texttt{weight}|$,
and traces the highest-weight upstream nodes back through the graph.
A node at layer $\ell$, token position $t$ with feature id $k$ and
large incoming weight indicates that transcoder feature $(\ell, k)$
encodes information that causally influences the prediction at that
position.

All attribution graphs produced in this work are publicly explorable
through an interactive visualisation tool at
\url{https://mechinterp-viz-94c364.uniofcam.dev/}.
Figure~\ref{fig:attr-graph-viz} shows the attribution graph for the
focus prompt, first with edges hidden to reveal the node layout, then
with all edges rendered.  Nodes are arranged by layer (columns) and
token position (rows); edge colour encodes sign (blue = positive,
red = negative) and node size encodes influence magnitude.
Interactive sliders filter by edge count and minimum influence threshold;
clicking a node reveals its upstream and downstream neighbourhood.
